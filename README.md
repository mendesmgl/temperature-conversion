# Temperature Conversion | Conversão de Temperatura

## English

A beginner-friendly C program that converts a temperature from Celsius to Fahrenheit using a function with floating-point input and output.

### Technologies

C

### How to run

Compile with GCC:

```bash
gcc temperature_conversion.c -o temperature_conversion
```

Run the program:

```bash
./temperature_conversion
```

### Example

Write `25` as the Celsius temperature. The program displays:

```text
Sua temperatura em graus farenheit é igual a: 77.0
```

### What I learned

- How to create a function that receives and returns `float` values.
- How to apply the Celsius-to-Fahrenheit conversion formula.
- How to read decimal input with `scanf()`.
- How to format decimal output with `printf()`.

### Future improvements

- Add validation for invalid or non-numeric input.
- Correct and standardize the user-facing messages.
- Allow the user to perform multiple conversions without restarting the program.
